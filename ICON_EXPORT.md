# App icon sizing and verification

1. Run `bash scripts/export-icons.sh` with the Xcode version listed in the README. The export keeps a 1024 × 1024 transparent canvas, centers the artwork in an 820 × 820 box, and adds a soft shadow. The PNG is the source for the ICNS and README preview.
2. Compare the actual download PNGs with Finder and several built-in icons. On macOS, the bundled references are `/System/Library/CoreServices/Finder.app/Contents/Resources/Finder.icns` and `Contents/Resources/AppIcon.icns` inside Preview, TextEdit, and Calculator under `/System/Applications`. Draw each full image into the same square at 128, 64, and 32 px. Preserve the original alpha and padding during resizing. Disable any trim or fit-to-content options.
3. Measure the bounding rectangle of pixels with alpha at least 50% for the main shape and at least 1% for the faint outer edge. Compare both and then inspect the icons side by side on the same background. Pay attention to the shadow, corner shape, and how the main shape reads at small sizes. Use the measurements as references, since resampling and macOS versions can shift the bounds by a pixel or two.
4. Confirm that all three PNGs retain transparent borders and that each ICNS decodes into all ten representations. Inspect the regenerated preview. When a macOS desktop is available, follow the README installation steps on a disposable copy of an app and compare it next to Finder in the Dock at the same size. Refresh the Dock if it still shows the previous icon.

With the macOS references used for this export, the 128 px comparison measured 102 × 102 px for the main shape in both sets. The faint edge measured 110 × 110 px for the built-in icons and 110 × 109 px for the Perforce icons. At 32 px, the faint edge measured 26 × 26 px in both sets, while the Perforce main shape measured 24 × 24 px versus 26 × 26 px for the built-in icons. These measurements are from rendering the image files side by side.
