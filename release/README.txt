Perforce P4 Alternative App Icons for macOS

Choose the PNG for your app: P4V.png, P4Merge.png, or P4Admin.png.
If the app is on the Perforce disk image, copy it to Applications first.

1. Open the PNG in Preview. Select all (⌘A) and copy (⌘C).
2. In Finder, select the app in Applications and press ⌘I (Get Info).
3. Click the small icon next to the app name, below the title bar.
4. Paste (⌘V). If the Dock still shows the old icon, quit and reopen the app.

To restore the original icon, select the small icon in Get Info and
press Delete.

Illustrated instructions and project information:
https://github.com/watr/perforce-p4-alternative-app-icons#installation

This is an unofficial icon set. It contains no installer.
